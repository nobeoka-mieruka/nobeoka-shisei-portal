# 議事録反映状況 監査レポート（データ修正なし・読み取り専用）

生成日時：2026-08-05

## 監査方法

延岡市議会 会議録検索システム（kensakusystem.jp/nobeoka）から、対象期間の全定例会について、
議事日程に「一般質問」が含まれる本会議日を特定し（各会期3日、計36日）、その日の発言者セグメント
一覧から議員名（役職接頭辞なしの発言者ラベル）を抽出して「実際に登壇した一般質問者」を機械的に
復元した。連続する同一議員の発言ブロックを1回の登壇としてカウントしている。

**制約・注意点**：
- 登壇＝一般質問1回とみなしているが、代表質問・関連質問・総括質疑が同じ日程枠に混在する場合を
  完全には区別できていない可能性がある（原文の項目見出しまでは今回精査していない）。
- 発言順が同一議員で分断される場合（議長発言などを挟む一問一答形式）は1回として正しく統合しているが、
  極端に複雑な進行があった場合に誤カウントの可能性が残る。
- 令和8年6月定例会は会議録が公式サイトでまだ未公開のため、今回の監査対象（令和5年度〜令和8年3月）
  には含めていない（ユーザー指定どおり）。
- 臨時会12件は対象期間内に含めて確認したが、いずれも議事日程に
  「一般質問」を含まなかった（臨時会は個別議案の審議が中心のため、制度上想定どおり）。
- **既知の制約への補正を実施**：同一議員が同一日に複数の質問区分（代表質問＋一般質問等）を行う場合、
  発言者セグメント上は連続した同一ブロックとして現れ、自動集計では1回にしか数えられない。
  サイト側は質問区分ごとに正しく別レコード登録していることを確認できたため（下表参照）、
  該当10件について実施回数を補正して集計している（本文を人力で
  再読して確認したものではなく、日付・区分の突合による機械的な補正である点に注意）。
