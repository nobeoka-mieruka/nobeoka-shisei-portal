## 7. 出典の健全性

### 修正した重大な問題

**個別施策33件すべての出典URL（`.../attachment/28741.pdf`）が HTTP 404** だった。33件すべてが `trustLevel: PRIMARY` を宣言しながら、市民が原本へ到達できない状態だった。
同一資料の到達できるURL（`.../attachment/28743.pdf`、HTTP 200・974,572バイト）へ差し替えた。差し替えの妥当性は、p.2〜p.7 の内容が各施策の `sourcePage` と一致することを目視で確認して判断した。

|---|---|
| 延岡市公式サイト（選挙公報ページ） | HTTP 404。選挙管理委員会事務局ページにも掲載なし |
| Wayback Machine | 2025年執行分の保存なし（対象ページの保存は2022-01-17の1件のみ） |
