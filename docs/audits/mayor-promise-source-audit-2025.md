## 10. 追補（2026年9月21日・公約本文の文言差6件と資料p.8の精査）

### 10-1. 文言差6件の結論：**いずれも誤りではなかった**

三浦久知市長の公式サイト（https://hisatomo-m.jp/）の政策セクションを原文で確認したところ、
掲載されている12項目が、当サイトの個別公約1-1〜4-3の本文と**一字一句完全に一致**した。

| 公約 | 当サイトの本文＝市長本人サイトの文言 | 延岡市の資料での言い回し |
|---|---|---|
| 1-1 | すべての子ども | 全ての子ども |
| 1-3 | 設置し子育て支援 | 設置し、子育て支援（読点あり） |
| 2-3 | 西階野球場 | のべおかwaiwaiスタジアム |
| 3-2 | 市民の命を守ります | 市民の生活を守ります |
| 4-1 | 発足します | 発足させます |
| 4-2 | チームを組む仕組みをつくり | チームを組み |

つまり「当サイトの本文が市の資料と違う」のではなく、**同じ公約を市長本人と延岡市が別の言い回しで
公表している**という関係だった。どちらかが誤りというものではないため、**公約本文は変更しない**。

前回（§9まで）の監査は、本文の出どころを延岡市の資料と記録し、6件を「文言に違いがある」と
説明していたが、これは出どころの取り違えだった。データの記録を次のとおり正した。

- 本文の出どころ＝**市長本人の公式サイト**（12件とも一字一句一致）
- 4-4・4-5 は市長本人サイトの政策12項目に無く、延岡市の資料で新たに確認された項目（出どころ＝市の資料、一致）
- 延岡市の資料側の言い回しは `cityDocument` として別に記録し、公約詳細ページにも併記する

結果、「公約本文が出典と一字一句同じもの」は **14／14件**、
「延岡市の公表資料でも同じ文言のもの」は **8／14件** となった（残り6件は市が言い換えて公表）。

### 10-2. 資料p.8「その他、公約関連の取組み」の扱い

資料p.8には、次の3項目が「その他、公約関連の取組み」として掲載されている。
