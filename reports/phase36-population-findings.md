# Phase36 調査報告：人口・基礎統計（1933〜2026年）

作成日：2026-08-22
対象データ：`src/data/nobeokaCensusPopulation.json`
編集範囲：本レポートのみ（`src/data/*`・`.claude/*`・その他既存ファイルは一切変更していない）

## 1. 開始時点の収録状況

`src/data/nobeokaCensusPopulation.json` の `series` は国勢調査（5年ごと・10月1日基準）のみを収録しており、21時点（大正9年＝1920年〜令和2年＝2020年）が揃っていた。

| 区分 | 状況 |
|---|---|
| `reconstructedCurrentBoundaryPopulation`（現行市域組替） | 1920〜2020の21時点すべて収録済み。欠落なし。 |
| `observedPopulation`（当時の行政区域＝合併前の旧市域） | **1980年の1点のみ**収録。1920〜1975、1985〜2020は`null`（未収録）。 |
| 令和7年（2025年）国勢調査 | **未収録**（2026年5月29日公表の速報値がまだ反映されていない）。 |
| 住民基本台帳人口（毎月・毎年基準日） | データ項目自体が存在しない（スキーマに項目なし）。 |
| 世帯数 | データ項目自体が存在しない（スキーマに項目なし）。 |
| 面積 | データ項目自体が存在しない（`municipalityComparison.json`側には別途`areaKm2`があるが、本ファイルの対象外）。 |
| mergerEvents | 2006-02-20（北方町・北浦町編入）、2007-03-31（北川町編入）の2件を収録。今回の調査ですべて整合性を確認できた（後述）。 |

「1933〜2026年」という調査対象年のうち、1933年は延岡市の市制施行年であり国勢調査の実施年ではないため、国勢調査ベースの`series`には該当時点が存在しない（既存データの設計上、国勢調査年のみを収録する方針のため、1933年を欠落として扱うのは適切でないと判断した）。

## 6. 作業要約

延岡市統計書PDF・stat.go.jp静的ページ・e-Stat配布xlsxを`curl`＋`pdftotext`／`unzip`＋`grep`／`awk`で直接パースし、令和7年国勢調査速報値（109,589人、世帯50,351）を新規に確認したほか、1985〜2005年の5時点についてobservedPopulation（合併前の旧延岡市域人口）の候補値を、北方町・北川町・北浦町の合併前人口との合計が既存のreconstructedCurrentBoundaryPopulationと完全一致することをもって検証した。住民基本台帳人口と面積の年次時系列は情報源のURLは特定できたが、環境上の制約（.xls解析ツール不在、時間予算）により数値確定には至らず、未解決として記録した。`src/data/*`は変更していない。
