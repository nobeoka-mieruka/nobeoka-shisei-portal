## 2. 推奨調査順序

同一施設・同一地域でまとめて確認できるかを優先し、交通効率と重要度（A1優先）の両方を考慮した順序です。

### ステップ0：オンラインで既に照会済み・回答待ち（訪問前に必ず確認）
- **INQ-001**（宮崎県立図書館、2026-08-21送付、UNR-014／015／027）
- **INQ-002**（宮崎県統計調査課、2026-08-21送付）
- → **重複照会・重複訪問をしないため、まず回答が届いていないか確認すること。** 届いていれば
  現地訪問の要否そのものが変わる可能性がある。

### ステップ1：延岡市内（市内で1日にまとめて回れる4施設）
1. **延岡市立図書館**（カルチャープラザのべおか内、〒882-0812 延岡市本小路39-1）
   - 対象：UNR-006・008・015・016・029、TASK-046（`nobeoka-library-checklist.md`参照）
   - 優先理由：市内・郷土資料担当が常駐、複数UNRを1回の訪問でまとめて確認可能
2. **延岡市役所（総務課・財政課）**（同じ建物内で複数部署を回れる）
   - 対象：UNR-013・014・015・020・027・029（`inquiry-drafts/soumu-ka.md`・`zaisei-ka.md`等）
   - 優先理由：図書館で確認できなかった場合の一次資料保管元。財政課→総務課→情報公開担当の
     順にエスカレーションする設計
3. **延岡市議会事務局**（市役所近隣）
   - 対象：UNR-005・008・009・010・011・016・022・031
4. **延岡市選挙管理委員会**（市役所内）
   - 対象：UNR-001〜004・016・028・029（M11・M13）

→ ステップ1は原則として市役所訪問1回でまとめて対応可能（議会事務局・選管は市役所内または近接）。

## 3. 持っていくものリスト

| 持ち物 | 必要性 | 備考 |
|---|---|---|
| スマートフォン | 必須 | 撮影・記録用。カメラのフラッシュは施設ルールで禁止の場合あり |
| モバイルバッテリー | 推奨 | 長時間の資料確認に備える |
| 筆記具・メモ帳 | 必須 | 撮影不可の施設・箇所に備える |
| UNRチェックリスト（本マスタープラン・各機関別チェックリストの印刷） | 必須 | `nobeoka-library-checklist.md`等を印刷して携行 |
| 資料番号一覧・請求記号一覧 | 必須 | 特に宮崎県文書センターの簿冊番号5043・107051 |
| 身分証明書 | 必須（要確認） | 施設によっては閲覧申込に必要。詳細は各施設へ要確認 |
| NDL利用者情報 | NDL訪問時のみ必須 | 事前にNDL利用者登録（無料）が必要。要確認：登録方法・持参物 |
| USB等の記録媒体 | 施設が許可する場合のみ | デジタル化資料の複写方法は施設ごとに異なるため**要確認** |
| 小銭・コピー代 | 推奨 | 複写サービスの料金は現金対応の施設が多い（金額は**要確認**） |
| クリアファイル | 推奨 | 複写物・資料の持ち帰り保護用 |

**「要確認」とした項目は、既存資料に記載がなく推測で埋めていません。訪問前に各施設へ電話等で
確認してください。**

## 4. 現地で記録する標準フォーマット

資料を確認できた場合は、以下の項目を**必ず**記録してください（`reports/phase19-onsite-research-plan.md`
の登録ルールとも整合させています）。

```
UNR ID：
資料名：
著者：
発行者：
発行年：
請求記号：
ページ（コマ番号含む）：
原文の要点（可能な範囲で原文を直接引用）：
確認した事実（数値・日付・氏名等、正規化前の原典値もあわせて記録）：
日付精度（day／month／year等、不明な場合はその旨明記）：
trustLevel（PRIMARY／OFFICIAL_ARCHIVE／SECONDARY／NEWS／SOCIAL／UNVERIFIED のいずれか）：
撮影ファイル名：
コピー番号：
確認日：
確認場所：
備考（複写可否・次に確認すべき事項等）：
```

記録後の反映手順：
1. `reports/phase21-inquiry-tracker.json`・`reports/phase33-master-unresolved-ledger.json`・
   `src/data/blockedTaskClassification.json`の該当レコードのステータスを更新する。
2. 確認できた数値・日付を`src/data`（`archiveFiscalYears.json`・`archiveMayorTerms.json`等）へ、
   出典（sourceUrl/sourceTitle/sourceOrganization/pageNumber等）とともに登録する。
3. `npm run validate:data`等の該当validationを実行し、errors=0を確認する。
4. 資料が見つからなかった場合も、その旨を記録し、UNRのステータスを安易にGREEN化しない
   （「見つからない」を「存在しない」に変換しない）。
