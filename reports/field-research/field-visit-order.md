## 1. 順序最適化にあたって考慮した要素

| 要素 | 本ドキュメントでの反映方針 |
|---|---|
| 同一施設で複数UNRを解消できるか | 施設ごとに対象UNRをまとめ、1回の訪問内で完結する順序にした（延岡市立図書館＝5件、延岡市役所関連4施設＝計17件） |
| 同一資料で複数UNRを解消できるか | 延岡市史上巻コマ124（M1〜M9、9区間）、コマ124-127（UNR-008・013）等、同一資料内の近接ページをまとめて確認する順序を維持（`nobeoka-library-checklist.md`「推奨する確認順序」を踏襲） |
| 閲覧申請に時間がかかるか | 図書館の郷土資料閲覧は現地判断だが件数が多いため最初の訪問先に配置。市役所内の照会は電話ベースの確認が中心で相対的に短時間と想定 |
| 事前予約が必要か | 全施設で予約要否が既存資料に未記載のため「要確認」と明記。特に宮崎県文書センターは電話等での事前確認が必須（`miyazaki-ndl-checklist.md`次のアクション） |
| 複写申請が必要か | 施設ごとに「要確認」列を設けた（既存資料に記載なし） |
| 開架／閉架資料か | 延岡市立図書館・宮崎県立図書館は郷土資料コーナー現物（開架相当と推定されるが未確認）、宮崎県文書センターは簿冊単位の請求（閉架相当と推定されるが未確認）として扱い、後者は事前照会の優先度を上げた |
| 事前照会した方がよいか | 宮崎県文書センター（所在地すら未確認）、秘書担当・広報担当・統計担当（直接連絡先未確認）は訪問前の電話確認を必須とした |
| 調査失敗時の代替資料 | 4章のUNR別マトリクスに「代替資料」列を設けた |
| A1優先度 | UNR優先度A1（17件）を各ステップで最優先に配置（`unr-priority-master.md`） |
| 移動効率 | 延岡市内→宮崎市内→NDL（東京・大阪）の地理的クラスタリングを基本とした（`field-research-master-plan.md`の既存順序を踏襲・詳細化） |

## 9. 未反映・留意事項

- 本ドキュメントは訪問「順序」の最適化のみを行っており、UNR31件のステータス（`reports/phase33-master-unresolved-ledger.json`）・優先度（`unr-priority-master.json`）は一切変更していない。
- 各施設の開館時間・休館日・予約要否・複写条件・撮影可否のうち、既存資料に記載がなかったものはすべて「要確認」「営業時間要確認」とし、推測で埋めていない。実際の訪問前に必ず電話等で確認すること。
- 宮崎県文書センターの「簿冊番号5043」「107051」は資料の請求番号（識別子）であり、件数ではない（`miyazaki-ndl-checklist.md`の注意書きを踏襲）。
- 現地・照会で得られた結果の反映手順（`src/data`への登録、validate:dataの実行等）は`field-research-master-plan.md`4章に従うこと。本ドキュメントでは新たな一次資料の確認・数値の確定は行っていない。

以上、既存資料の整理・順序最適化のみを行った。
