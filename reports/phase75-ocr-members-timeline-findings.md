# Phase75：広報OCR・元議員・市政年表 調査結果

作成日：2026-08-23
担当：Phase75 worker

## 0. 方針・手法

- Phase63の手法（`kohoOcrSearchIndex.json`のOCR候補→対象PDFを`curl`で取得→Windows PowerShell 5.1 + WinRT `Windows.Data.Pdf` APIでPNG画像へ実レンダリング→目視照合）を再利用した。レンダリングは`powershell.exe`（Windows PowerShell 5.1、`pwsh`ではない）から実行する必要があった。`pwsh`（PowerShell 7）からWinRT相互運用を呼び出すと`GetParameters`で`Operation is not supported on this platform`エラーとなり動作しないことを確認した（今回新たに判明した制約。次回作業者への申し送り）。
- レンダリングスクリプト・ダウンロードしたPDF・生成PNGはすべて本タスクの一時ファイル（`scratchpad`配下）にのみ保存し、`src/data`等の対象ファイルには一切手を加えていない。
- OCR文字列だけでは氏名・日付を確定せず、原紙PDF画像で確認できたものだけを「確定」として扱った。画像照合ができなかった候補は「未確定（候補のまま）」とした。
- 元議員の補強は、新規の外部Web検索ではなく、`src/data`内の**既に検証済み（verificationStatus: verified）の`civicTimelineEvents.json`**（会議録検索システム・広報のべおか原典に基づく）とformerMembers.jsonを突合し、まだ接続されていなかった一次資料済みの事実を発見する内部横断調査を優先した（「広報のべおか・議会だより等の未使用ルート」のうち、議会だよりは後述のとおり物理資料アクセスが必要でBLOCKED状態のため、今回は広報のべおかOCRおよび既存の検証済み内部データとの突合を実施した）。

- **確認できた内容**（PDF画像目視、判読良好）：見出し「議長に松田満男氏 副議長に早瀬賢一氏」。本文「5月15日(月)、16日(火)に行われた臨時市議会で、新しい議長に松田満男氏、副議長に早瀬賢一氏が選ばれました。また、議会選出監査委員に中城あかね氏が選ばれました。任期は令和9年5月1日までです。」

- **確信度**：高（実PDF画像で本文全文を判読）
- **分類**：行政組織（議会人事）
- **既存データとの関係**：`src/data/civicTimelineEvents.json`には2019年5月16日の議長交代（civic-166、松田和己氏が議長、松田満男氏が副議長）までは記録済みだが、2023年の交代（松田満男氏が議長へ昇格、早瀬賢一氏が新副議長、中城あかね氏が議会選出監査委員）は未記録だった。**市政年表への新規追加候補として`phase75-ocr-members-timeline-findings.json`に構造化した。**

### 候補G．北林幹雄氏、副議長選出（2022年5月9日臨時市議会）— **未確定（候補のまま、画像照合できず）**

- **号・ページ**：`koho-2022-06`（広報のべおか2022年6月号、`https://www.city.nobeoka.miyazaki.jp/uploaded/attachment/10090.pdf`）PDF page 11
- **OCR原文**：「い副議長が選出されました５月9日㈪に臨時市議会が開かれました。この議会では副議長の選挙が行われ、北きたばやし林幹みきお雄議員（」（`kohoOcrSearchIndex.json`より、keyword: 選挙、市議会）
- **未確定の理由**：`10090.pdf`（26,352,198バイト）をcurlで取得できたが、Windows PowerShell 5.1 + WinRT `Windows.Data.Pdf.PdfDocument.LoadFromFileAsync`で読み込み時に**HRESULT 0x80048040の例外**が発生し、ページ単位のレンダリングに失敗した（ファイル全体のロード自体が失敗するため、特定ページの問題ではない）。ダウンロードはHTTPヘッダのContent-Length（26352198）とファイルサイズが完全一致しており、通信起因の破損ではない。原因は当該PDFファイル自体がWinRT PDFレンダラー非対応の内部構造（埋め込みフォント・画像形式等）を持っている可能性が高い。
- 北林幹雄氏は`src/data/members.json`のm11（現職議員、3期目）に該当する人物であり、`formerMembers.json`の対象ではない。
- **次回への申し送り**：別のPDFレンダリング手段（例：他マシンでのAdobe/Chrome印刷、または`pdfium`系ツールの導入）で当該ページの原紙照合を行い、確認できれば市政年表候補として追加を検討すること。今回は確定候補に含めない。

- **warnings**：
  1. `koho-2022-06`（`https://www.city.nobeoka.miyazaki.jp/uploaded/attachment/10090.pdf`）は、Windows PowerShell 5.1 + WinRT `Windows.Data.Pdf`でファイル全体のロードに失敗する（HRESULT 0x80048040）。ダウンロード自体は正常（Content-Lengthと一致）であり、PDFファイル自体の内部構造に起因すると推定される。次回、別のレンダリング手段での再挑戦が必要。
  2. `pwsh`（PowerShell 7、本環境のPowerShellツールの既定シェル）からはWinRT相互運用のリフレクション呼び出し（`[System.WindowsRuntimeSystemExtensions].GetMethods()`)が`Operation is not supported on this platform`で失敗する。原紙PDF画像照合を行う際は、必ず`powershell.exe`（Windows PowerShell 5.1）を明示的に呼び出す必要がある（Bashツール経由で`powershell.exe -File ...`を実行するのが確実）。
  3. 候補Fの議長・副議長選挙が「5月15日・16日」のいずれの日に実施されたかは、広報のべおか本文からは一意に確定できなかった（両日にわたる臨時市議会の開催のみ明記）。過去の類似事例（civic-166等）では議長選挙が2日目に行われるパターンが多いが、本件は会議録原典未照合のため、市政年表への反映時は日付を「2023年5月15日〜16日」の範囲表記とするか、会議録検索システムでの追加照合を推奨する。
  4. fm21（高橋勝）と`billVotes.json`の「高橋勝栄氏」（教育委員会委員）は氏名が完全一致しないため別人と判断したが、念のため次回作業者は両者が本当に別人であることを追加確認することが望ましい。
  5. 「議会だより」ルートは物理資料アクセスが必要（TASK-101、BLOCKED）なため、オンライン調査の範囲では今回も新規情報を得られなかった。この制約は今後も変わらない見込みであり、次回以降は物理資料調査（Phase29計画）との連携が引き続き必要。
