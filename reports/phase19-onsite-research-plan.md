# Phase 19：現地調査パッケージ（総合計画書）

作成日：2026-08-20
対象：財政欠落9年度（FY1951・FY1952・FY1953・FY1959・FY1983・FY1984・FY1985・FY1986・FY1987）

本ドキュメントは、Phase16〜18のオンライン調査結果をもとに、現地調査（図書館・市役所への照会／来館閲覧）を1回行った際に最大限の成果を得るための実用パッケージである。**新規のオンライン検索は行わず、既存の調査結果のみを再整理した。**

関連ファイル：
- `reports/phase19-resource-dossier.md` — 候補資料の完全整理（資料名・発行年・所蔵機関・請求記号等）
- `reports/phase19-missing-years-matrix.json` — 欠損年度×資料マトリックス
- `reports/phase19-library-inquiry.md` — 宮崎県立図書館・延岡市立図書館・延岡市役所向け照会文
- `reports/phase19-research-checklist.md` — 現地調査チェックシート

## 1. なぜ現地調査が必要か（Phase18までの結論の要約）

- 延岡市史上巻（NDLデジタルコレクション、pid 9774711）の財政章を精読・全文検索したが、FY1951-1953・FY1959に該当する一般会計歳入歳出決算の記述は発見できなかった。
- 宮崎県統計年鑑は第101回（昭和57〜58年、1985年発行）までしかNDLデジタルコレクション化されておらず、その最終版も市町村別決算データは昭和57年度（1982年度）分までしか収録していない。第102回以降（FY1983-1987を含むと推定される版）は紙媒体のみである。
- 地方財政統計年報は、デジタル化されている巻も「国立国会図書館内限定公開」（個人送信サービス対象外）であり、遠隔からの本文閲覧ができない。
- 以上より、残存9年度についてはオンライン調査の限界に達しており、物理資料へのアクセス（図書館への照会・来館閲覧）が必須という結論に至った。

## 2. 推奨する現地調査の順番

`reports/phase19-missing-years-matrix.json` の `recommendedReadingOrder` と同一内容だが、要約すると以下の順で進めることを推奨する。

1. **延岡市決算書並意見書**（宮崎県立図書館等で所蔵確認）— 1950年代4年度（FY1951・1952・1953・1959）を一括で埋められる可能性が最も高い最優先資料。
2. **宮崎県統計年鑑 第102〜106回**（宮崎県立図書館等で所蔵確認）— 1980年代5年度（FY1983-1987）を一括で埋められる可能性が最も高い最優先資料。
3. **〔延岡市〕市政二十年史** — FY1951・1952の補完。
4. **地方財政統計年報**（国立国会図書館） — 宮崎県統計年鑑で埋まらなかった1980年代分の代替。
5. **延岡市統計月報等** — 内容未確認のため、他資料の合間に確認。
6. **延岡市議会会議録（旧会期）** — FY1959の決算認定議案審議記録として補助的に参照。

**理由：** 資料1と資料4はいずれも「1回の閲覧で複数年度を一括で埋められる」構造（決算書は複数年度分を合冊、統計年鑑は連続刊行物）であるため、投資対効果が最も高い。この2つの所蔵確認を最優先で行うことで、現地調査の回数を最小化できる。

## 3. データ登録ルール（現地調査で得た数値の登録方法）

現地調査で数値を確認できた場合、`src/data/archiveFiscalYears.json` 等へ登録する際は以下のルールを厳守する。

### 3.1 confirmed_primary の条件

以下をすべて満たした場合のみ `confirmed_primary` として登録する。

- 一次資料（延岡市自身が作成した決算書、または国・県の公的統計）を**直接**確認したこと（伝聞・二次資料からの孫引きは不可）
- 対象年度が資料内に明記されていること（推測で年度を割り当てない）
- 延岡市であることが明記されていること（他市町村の数値との取り違えがないこと）
- 会計区分（一般会計／普通会計／特別会計）が明記されていること
- 決算額／決算見込額／予算額のいずれであるかが明記されていること
- 単位（円／千円／百万円等）が明記されていること

いずれか1つでも確認できない場合は `confirmed_primary` としない。`located_partial_read`（部分確認）等の既存の状態語彙を使う。

### 3.2 写真・複写を取得した場合の記録項目

- 資料名（正式名称）
- 発行者
- 発行年
- 表題（資料に印刷されている通りの文言）
- ページ番号／コマ番号
- 撮影日
- 撮影番号（ファイル名）

これらは `sourceRefs` の各エントリに `sourceTitle`・`pageNumber`・`accessedAt`・`notes` として記録する（既存の `archiveFiscalYears.json` のスキーマに準拠する）。

### 3.3 原典値と正規化値の分離

- 資料に印刷されている単位（例：千円）のままの値を、まず `notes` に「原典値：24,294千円（単位=千円、原文ママ）」のように明記する。
- `totalRevenueYen`・`totalExpenditureYen` 等のフィールドへ登録する際は円換算（×1000等）した正規化値を入れるが、**変換前の原典値を必ず併記し、変換の過程が追跡できるようにする**。既存のFY1950・1955・1981のレコードも同じ方式（原典値は千円、フィールドは円）を採用しており、これに合わせる。

### 3.4 市町村税と歳入総額の混同禁止

FY1954の既存レコードで、市町村税（349,792,071円）と歳入総額（762,402,000円）が別の表・別の出典から確認されていることに注意する。今後新たに数値を確認する際も、「税収」「歳入総額」「歳出総額」「決算見込額」など、表題に書かれている項目名を正確に読み取り、混同しないこと。

### 3.5 既存データの保護

以下の年度は既にconfirmed_primaryとして登録済みである。**新たな根拠なく変更しない。**

FY1933, 1949, 1950, 1954, 1955, 1956, 1957, 1958, 1960, 1961, 1962, 1963, 1964, 1965, 1966, 1967, 1968, 1969, 1970〜1980, 1981, 1982, 1988〜2026

現地調査でこれらの年度に関する追加情報（別の一次資料での再確認等）が得られた場合も、既存値を上書きするのではなく、`sourceRefs` に追加のエントリとして記録し、既存値との整合性を `notes` に明記する方針とする。

### 3.6 mayorId / mayorTermId の割当

新規年度を登録する際は、`scripts/link-fiscal-years-to-mayors.mjs` の既存ロジック（会計年度4/1〜翌3/31が単一の市長任期に完全に含まれる場合のみ機械的に割り当てる）を必ず適用する。年度途中で市長が交代している場合は割り当てず、`notes` に両市長の任期IDを事実として記録するに留める。

## 4. 品質検証（現地調査後にデータを追加する場合）

新規年度を登録した後は、必ず以下を実行する。

```
npm run validate:data
npm run validate:finance
npm run validate:sources
npm run typecheck
npm run lint
npm run build
```

- `validate:data` の warnings は現在15件。新規warningを増やさないこと。
- `scripts/link-fiscal-years-to-mayors.mjs` を再実行し、mayorId/mayorTermIdの矛盾がないか確認すること。
- 新規年度について `/timeline/<year>` ページを実機確認し、0円・null誤表示・グラフの不自然なゼロ落ちがないことを確認すること。

## 5. 本パッケージの限界

- 請求記号・所蔵館の確定情報は、今回のオンライン調査だけでは得られなかった。本パッケージの照会文はこの空白を埋めるためのものであり、回答を得るまでは現地調査の具体的な訪問先を確定できない。
- 宮崎県統計年鑑第104回の書誌そのものが今回のNDL検索でヒットしなかった（欠番の可能性、または検索キーワードの問題）。照会時にあわせて確認することを推奨する。
- 「延岡市統計月報」等（資料3）は書名の存在確認のみで、実際に延岡市の財政データを含むかどうかは現物を見るまで分からない。過度な期待をせず、他の資料と並行して確認する位置づけとする。
