## 3. 主な発見（詳細は`shishi-index.json`参照）

1. **歴代市長（Phase138）**：本資料の歴代市長節が実際に記載するのは第23代・櫻井哲雄（3期目のみ）と
   第24・25代・首藤正治（1・2期目）の2名のみ（本資料の対象期間のため）。市長選挙の投票日・得票数
   （2002-01-27／2006-01-29／2010-01-24、得票数は本文参照）が、既存archiveMayors.json・
   archiveMayorTerms.jsonの登録値と**完全一致**（矛盾0件）。就任日の日単位精度は本資料でも
   未記載のため、既存の未確認部分（termStartPrecision="month"）は変更していない。
2. **人口データ（Phase135）**：新延岡市域（旧3町含む再構成）の国勢調査人口
   （2000年139,176人／2005年135,182人／2010年131,182人）が、既存
   `nobeokaCensusPopulation.json`と完全一致。
3. **財政データ（Phase137）**：平成13〜23年度（2001-2011年度）の詳細決算統計を確認したが、
   既存の欠落年度（FY1951-1953・1959・1983-1987）とは対象期間が重ならず、欠落年度の穴埋めには
   使用できなかった。
4. **歴代議長・副議長（新規発見）**：第47〜60代（2001-2012年）の在任期間が日単位で判明。
   TASK-101（`blockedTaskClassification.json`）へ追記し、2001年以前分の未解決をUNR-032として
   新規登録した。データベースへの投入（新規データ型・UI）は次フェーズ課題とした。
